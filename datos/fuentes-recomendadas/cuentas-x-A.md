# Cuentas de X recomendadas, bloque A (macro/tasas, mercados/flujos, USD/MXN y México, cripto, geopolítica/OSINT)

Fecha de elaboración y corte: 2026-10-06. Solo información pública (REGLAS-MOTOR §0). Tipo de fuente de este documento: cálculo propio de curaduría sobre sitios oficiales y búsqueda web.

## Cómo se verificó cada handle

- **V-A (fuerte):** el sitio oficial de la institución o de la persona (o su página institucional) enlaza ese handle exacto. Se leyó la página el 2026-10-06.
- **V-B (media):** fuente independiente (prensa o página de terceros) que cita el handle exacto, hallada por búsqueda web. Es más débil que V-A, porque el resumen de la búsqueda no es la página original.
- El perfil de X no se pudo abrir (el sistema no entra a X). No se comprobó que el handle siga activo ni su ritmo de publicación.

## Advertencia general

1. La actividad actual de cada cuenta NO se pudo comprobar sin acceso a X: pueden estar inactivas, renombradas o con otro tipo de contenido. Tampoco se midió su historial de aciertos. Hay que dejar que el marcador del sistema lo califique con datos reales.
2. Nada de X es evidencia por sí solo. Toda afirmación que el dueño pegue se gradúa D/C hasta confirmarla en fuente primaria (A). Las cuentas oficiales sirven para localizar el dato; el dato se cita desde el comunicado o la base original.
3. Las listas de "influencers" de las que salieron algunos handles son listículos (emprendedor.com) y no prueban calidad. Se usaron solo como segunda fuente del handle, y cada cuenta se eligió por su credencial.
